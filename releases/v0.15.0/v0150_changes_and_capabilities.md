# v0.15.0 更新、能力与边界

## 基线审计

r4 可复用真实库存、动作结果和交付数量核验，递归材料与工具准备，附近科技站检查，暂停／恢复／取消、补状态暂停与知识会话。旧限制：制作器只允许六个基础配方，多目标首个受阻便整体停止；没有共享授权仓库和存放目的地，任务固定短时限。

本轮不新增主动照顾、建筑制作、耕种、战斗、拆除或点火。知识库仍是756039部分确认数据，保持全面知识最终目标；其身份3,067、基本介绍1,561、完整百科审查0的边界不因制作框架扩大而变成全部覆盖。

## 友谊容器

支持 treasurechest／dragonflychest 的原版与弹性空间升级状态、icebox、saltbox。原实体加 ybf_friendship_container 组件，保存授权布尔值；不替换实体，不搬运皮肤、内容物或原版功能。容量、堆叠、保鲜、接收规则仍由原组件管理。官方升级在同一实体开启无限堆叠；授权与名称随组件保存保留。拆毁或烧毁后不把旧实体当有效仓库；坍塌物不是新授权仓库。

手持任意友谊小花悬浮于支持容器，右键“赋予友谊”。服务器核验花有效且由操作人持有、容器类别和距离；花不消耗，重复赋予不叠加，数量无限。容器右键“解除友谊”，恢复名称，内容保持不变。授权所有朋友共享，无玩家／花／朋友绑定。客户端 net_bool 驱动“友谊＋原显示名称”与交互标记，服务器组件决定实际存取。没有改造原版UI槽位或接收函数。

普通容器默认完全禁止自动存取。泛指箱子解释为友谊容器；明确指普通箱会说明未授权。指定容器GUID须属于本任务局部发现且已授权的容器，不能开放普通箱权限。玩家原有取放不受限制。

## 仓库与可靠转移

搜索以朋友和任务起点为双重局部边界，沿用至少32世界单位的配置半径，不扫描全世界或跨分片。记录最近实际发现的授权容器，最多64个、10分钟过期，当前候选最多32个；短暂缓存只缓存实体引用，物品和授权仍实时核实。模型仅接收最多8个容器、各8条内容摘要，不能当精确可用库存。

预留以实际物品实体、任务、数量和短期有效期协调多个朋友；其他任务不能重复计入已预留的份额。取用动作前重新检查授权、距离、物品归属与实际数量。玩家可以正常取走，不锁容器；暂停、取消、失败、离开和到期释放。冲突后重读，不创建替代物品。

使用真实 RemoveItem／GiveItem，遵守 CanTakeItemInSlot／CanAcceptCount，每个转移动作最多10件、逐件核对收发。部分存放按实际数量记账；不会为了腾空间丢装备或任务材料。未确认的数量变化停止并要求检查，避免重复交付。

## 通用制作与获取

制作能力改由运行时有效配方驱动，不再扩充物品白名单。直接名称优先；产物身份与配方名不同时，只有唯一安全候选才绑定。普通可携带非建筑、非dropitem、非manufactured配方进入通用执行器：读取材料、产量、批次、材料折扣，递归展开中间材料（深度12／节点256）并给出合并需求视图；真实材料消耗与产出再验证。

真正制作前检查 Builder、已解锁或当前科技、角色／技能、recipe.canbuild、材料选择和空间。附近实际 prototyper 可以靠近解锁；站点已有才使用，不主动建站。正式 BUILD 负责消耗材料与原版事件，不免费生成或绕过解锁。免费／预付模式拒绝。材料消耗会释放的真实背包槽位可以保守计入产物空间；不假定未知物品堆叠上限。

获取动作：地面拾取、可可靠读产物的普通采摘、原有安全许可内的砍伐与开采；新增授权仓库取用和存放、明确任务的附近地面放置。工具按实际tool/equippable／耐久判断，必要时准备普通斧／镐，坏了替换，次数随目标扩展但仍有上限。多来源先按库存和实际可执行来源选择，可制作中间材料与可拾取成品均可复用。工具类目标尽量排在其他产物之后交付，以复用已准备工具。

认识配方 ≠ 可制作 ≠ 能自主取得所有材料。配方存在但条件或来源不足会保留进度并说明具体阻碍。

## 多目标、来源与目的地

支持最多8个目标，每项数量1–100（材料展开最多16项），可以分别 obtain（凑够总量）或 craft（新增制作量），并分别指定去向。共同材料需求合并为规划视图；执行每步重算，不把视图当库存。其他最终目标中的原料和成品份额受到保护，不全消耗为中间材料。中间产物保留在朋友库存，完成后按目标交付。

根据工具与实际条件安排顺序，允许分批获取／制作／交付；一个目标受阻继续其他可行目标，然后汇报部分完成与剩余阻碍。没有任意优化所有背包／路径／配方组合的全局最优调度器；空间仍不足时保留物品并报告。

默认材料来自自身库存与局部友谊仓库，不自动取玩家背包。“箱里有材料／先用箱，不够再找”优先仓库，实际核实后补获取；“只用箱里的”只计该任务取出的仓库材料与其加工产物，原有自身材料不能顶数，短缺不外出采集。“只用自己库存”不取仓库也不采集。既有 existing_only 限制保留。

明确目的地优先：玩家、已知唯一友谊容器、范围内指定地面点或朋友持有。泛指存箱会选择合适友谊容器；指定容器不可用则说明阻碍，不擅自替换。未指定 auto：优先合适仓库，再玩家，最后附近安全可达地面并报告位置。盐盒可接收食材优先盐盒；其他冰箱可接收物品优先冰箱；其余箱／龙鳞宝箱。实际接收规则优先，兼容堆叠与距离作为排序依据，满了尝试其他候选。

提供追加／删除／改总量：再加是增加数量，凑够按总量；修改保留真实已制作／交付，失效旧动作回调。取消最后一项目标取消任务；多目标不明确哪项会确认。用途背景不追加耕种、战斗等任务。数量与名称仍经过严格本地校验；知识查询不触发工作。

## 预算与失败

取消固定一分钟整体限制。单动作仍有限停滞时间（原动作适配），搜索范围和失败次数独立受限；目标任务预算按数量、目标数和动作增长，最多两小时，连续180秒无有效推进会停下。有效动作延长进展窗口，补状态暂停不计作停滞；手动暂停冻结工作，恢复重新核实。

阻碍包含具体目标、阶段和缺少条件，已存入／已给玩家／已放地面分别记账，物品仍保留。未确认收发或消耗不能自动重试成成功。普通暂停／恢复有进度版本，历史不会重放旧命令。

## 尚不支持或不能保证自主完成

- 所有建筑放置、战斗、拆除、挖植物、耕种、种植、主动照顾。
- manufactured 专用加工站、dropitem特例、皮肤解锁专用产物，以及消耗角色生命／精神等 character_ingredients 的特殊配方；原因是该类产出／消耗审计尚未接入。
- 烹饪、晾晒、交易、钓鱼、捕捉、挖掘、特殊转换的自主获取执行器未新增；可以取用授权库存中已有材料，但不会凭知识执行这些动作。
- 角色／技能不符、科技或必要站点缺失、仅战斗掉落且仓库无库存、未知动态来源、超出当前任务分片或范围，均不能自行补齐。
- 满包或无法安全卸下的装备、所有容器拒收、危险／不可达指定地面、路径失败等可能阻碍完成。会保留物品，不能称所有普通物品任务已游戏验证。

普通非建筑配方执行框架已打通；官方所有可制作物品的自主任务完成率未审计，本轮不以配方数量或模拟样本作为全覆盖承诺。
