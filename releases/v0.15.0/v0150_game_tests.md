# v0.15.0 精简游戏验收

测试包无真实游戏实测记录。先同时更新模组与后台，保留密钥；检查 health.version=0.15.0，静态知识构建756039。建议备份测试存档。

1. 各准备箱子、龙鳞宝箱、冰箱、盐盒。手持友谊小花悬浮右键赋予，重复赋予不重复名称、花数量不变；第二位玩家用另一朵花再赋予。所有朋友可使用。右键解除后仍能正常由玩家取放，内容、皮肤、容量、保鲜不变。保存退出、重启服务器再检查授权与客户端名字。
2. 授权箱与龙鳞箱使用官方弹性空间制作器升级（也测试先升级再授权）；原堆叠功能与友谊名保留。已有内容不丢失。至少联机两个客户端检查显示和操作。
3. 相同材料放普通箱与友谊箱，要求“只用箱子里的材料做一把黄金铲，做完存回去”。只能取友谊箱；短缺不采集。用普通箱作明确目的地应拒绝自动权限。再试“先用仓库的，不够再找”。
4. 用盐盒可接受的生食材、其他可放冰箱食物和普通工具组成任务，未指定去向应正确分流；让一个箱满、一个仅剩部分容量，再让玩家包满，检查部分存入／玩家交付／附近地面回退数量与位置。明确给玩家或特定箱时尊重该目的地。
5. 两个朋友同时请求同一箱里最后几份材料；玩家中途拿走、关授权或拆掉箱。不能复制、重复计数或持续锁玩家库存；暂停／取消一方后另一方能重新取用。实际寻路失败的容器尝试其他合理候选。
6. 选本轮未做对象特例的背包、橄榄球头盔、黄金干草叉或多用工具；准备材料与实际科技站测试制作及解锁，再移走站点和换不同资格测试。用“一个装备和若干它所需原料”混合请求，原料份额不得全部消耗。多层中间材料按真实库存与批次更新。
7. 两个目标，其中一个缺特殊材料或科技，另一个材料齐全；可行目标仍完成。途中“先暂停”“继续”“再加两个某物”“不要某目标了”“改成总共三个”“取消”。观察不会重复做已交付部分，取消后旧动作不执行。
8. 使用大量普通物资任务持续超过一分钟，确认仍有效推进；人为阻断路径／撤材料后应有限重试并具体汇报，不能无限等待。工具损坏应准备替换，不丢其他装备。
9. 回归“普通镐和黄金镐有什么区别”“猪人吃了4个怪物肉会怎样”、遮阳棚确认及指代，不触发工作。普通花瓣采集交付、另一普通采摘、暂停／取消、低状态补给各做一次必要回归。

失败时开启“知识诊断”或保存工作日志，记录原句、完整同请求链、各库存变化与目标进度。源码／模拟日志能定位流程，不能代替以上真实模型和游戏验收。
