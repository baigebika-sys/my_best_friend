# v0.16.0 更新、支持范围与交接

## 审计与架构

复用r1的库存核验、授权仓库取用／预留、递归中间材料、工具准备、科技站判断、混合目标和任务预算。没有重写获取或非建筑制作。新建筑目标由ybf_building独立执行；ybf_build_positions负责只读坐标，ybf_build_control负责服务器点选授权与任务修订，ybf_build_pick_client与本地无网络标记负责短暂交互。沿用名称索引与限定词保护；仅把原有“制作上下文的唯一可执行配方”判定接到建筑能力，并接受建筑量词，未扩充模糊名称词典。

每项建筑有稳定target_id、实际配方／产物、mode、world、origin、position、rotation、status、已核实实体记录和阻碍。状态区分等待定位、材料齐全、原版预制、实体核实、结果未确认。快照只包含可序列化摘要与最近6个实体GUID／坐标，不发送实体或整个百科。详细实际记录留在任务内。

正常流程：确定并检查位置→已有材料系统补齐→实际科技／资格检查→原版Builder:BufferBuild消费材料并保留buffered_builds→朋友靠近→服务器重新Map:CanDeployRecipeAtPoint→正式BUILD/Builder:DoBuild→核实本朋友此次buildstructure事件产物、GUID、位置、方向、预制解除及库存没有再次扣材料。仅动作成功信号没有真实实体不能算完成。异常结果停止重试，不通过改位置绕开审计。

原版BufferBuild自身负责解锁、临时科技和材料消耗；原版DoBuild消费预制并创建实体及OnBuilt事件。不直接SpawnPrefab建筑、不免费创造、不清除已有buffer。暂停与改位置使动作token／回调和点选nonce失效，固定坐标、已完成实体、预制状态保留。取消或替换任务反馈剩余预制。Builder原生保存支持预制跨重载；未新增完整工作队列跨重启保存。

## 实际能力与边界

支持实际运行时唯一普通placer配方、单产物、常规地面建筑；继承原版占地、recipe.testfn/canbuild、科技、解锁、角色与技能条件。普通建筑由数据驱动，不为木牌等测试对象编写执行分支。依旧不能保证所有材料都有自主获取动作；库存或友谊容器中已有的特殊材料可复用。

自由范围为原任务原点12单位内、候选最多81个；固定和地皮目标也受现有32以上配置工作半径约束。实际路径由原版locomotor执行、动作和任务仍有预算；自由候选可用Pathfinder直线检查做保守筛选，不能据此声称已经有绕任意障碍的路径规划。找不到或路径失败会报告，不扩大搜索到全图。

施工占位按实体任务、分片、位置、真实min_spacing（最小协调间隔0.25）管理，40秒过期，规划时续约；暂停、取消、失败、离开释放。只协调朋友，不锁玩家世界。现场变化用服务器地图规则重新核实。遮挡诊断复用原版过滤与当前版距离判定；仅可携带地面物品且空间足够时拾取，不对植物／结构动手。自定义占地规则未适配，不试探性清场。

不支持水上、船只／码头／铺地、移动平台建筑；自定义overridecandeploy、特殊施工sg_state、manufactured／dropitem、皮肤解锁、生命／精神等角色材料、多产物或动态产物建筑暂拒绝。它们需要各类消耗／状态／移动坐标或产物审计，不能凭配方存在打开执行许可。可可靠通过原版testfn检查的普通特殊地形条件依旧由服务器判定；角色或站点不符时报告。

不支持背包物品的deployable放墙／铺地等独立部署流程；本轮只实现建筑placer流程。没有建筑蓝图、组合、录制、自动布局、主动照顾、耕种、种植、战斗或拆除。缺制作设施只报告用途和条件，需玩家明确发起建筑目标后才施工。

建筑数按本次新增，不用既有建筑抵扣；“区域凑够”未建立明确区域对象计数，需说明新增量。固定点逐座点选，地皮单点多座必须改定位方式，不推导蓝图。最多8个目标、每项1–100仍沿用旧协议；进度有效时动态预算延长，保留停滞／搜索／动作上限。

静态报告tests/v0160_building_recipe_audit.json检出109条已有确认字面placer配方，108条仅是静态条件候选、1条需要进一步类别审核；动态或未确认条目不包含于这个数。这不是官方建筑总数、支持完成数或成功率；真正任务需要运行时资格、材料、位置与实体结果全部通过。全面知识覆盖边界不变，仍不能声称全部百科或全部建筑任务已完成。
