# v0.16.0 定位操作与最少游戏验收

## 三种定位

- 附近自由：例如“在附近建一个木牌”。在本任务起点12单位内，最多81个候选，优先原点和较近位置；使用服务器原版地图放置检查，可用原版直线路径检查作保守筛选。不是基地规划，不拆除或砍植物来腾建筑位置。
- 固定点选：例如“在我指定的位置建一个鸟笼”或“在这里建一个鸟笼”。收到点选提示后，聊天窗关闭，左键地面记录固定坐标；Q/E每次调整45度朝向，右键或Esc取消。只接管这次点选，不由玩家造建筑或消耗材料。HUD按钮／覆盖窗口上的点击不作为地面位置。提交显示短暂地面标记和坐标反馈，标记不是合法放置保证。朋友实际施工；玩家随后移动不影响坐标。点选90秒过期，或任务暂停／取消／修改使旧点选失效；再说“改为指定位置”可重新点选。当前交互按鼠标键盘实现，手柄未验收。
- 地皮对齐：例如“按脚下地皮中心建一个木牌”，自动取单格中心、两格公共边中点或四格公共交点。也可说“按这格中心建”“按这两格中间建”“按这四格交点建”。服务器收到有效请求时记录玩家站位和分片，模型等待期间移动也不影响原点。使用GetTileCoordsAtPoint和GetTileCenterPoint及相邻格中心计算，没有硬编码格宽或世界原点。默认吸附阈值为当前格宽15%，可在模组设置改10%／20%；角点优先于边，边优先于格中心。明确单格可覆盖自动吸附；明确两格时靠边且避开交点，四格时靠近交点，否则询问。不同地皮类型不影响对齐，不会铺地皮。

未说明位置会保留任务，简短询问定位方式；回答“附近找个地方建”“改为指定位置”或具体地皮要求。多项待定位时请带建筑名，避免给所有目标套同一个点。已选建筑朝向还可说“木牌朝向90”，范围0–359度。

固定或地皮位置非法会停下该目标，不偷偷偏移。固定数量多于一座会逐座请求新的点击；地皮单个中心只对应一座，多座需改为分别点选或自由选址。没有布局、组合或蓝图功能。建筑数量按新增建造，不计附近旧建筑；“区域凑够”尚没有区域计数接口，需要明确新增数。

## 精简验收（真实游戏尚未执行）

使用测试存档，准备友谊箱、所需材料和已解锁配方／科技站。优先测试用户指示之外的木牌、晾肉架、避雷针、鸟笼、帐篷。把难以自主取得的材料预先放友谊箱，不用控制台代替任务结果。

1. 先验证r1小花左右键赋予／右键解除，普通箱不被自动取用。问“木牌怎么制作”应只回答、不工作；再说“在附近建一个木牌”，记录新实体与坐标、材料实际减少。大量障碍或不可用地形时应有限搜索后报告，不自动拆除。
2. “在我指定的位置建一个鸟笼”：点一个地面位置，Q/E转向后提交；移动玩家，建筑应仍在原坐标。再次请求点选后右键、Esc各取消一次，正常点击应恢复，不能误开暂停菜单或启动玩家建造。聊天窗、HUD按钮上的点击不应提交。
3. 分别站格内中部、横向公共边、纵向公共边、四格交点，执行地皮自动对齐；在远离地图原点的另一区域重复。查看标记与反馈，移动后坐标不变。比较10%／20%吸附边界；站边却明确单格应取单格中心，明确两格／四格但站位不足应澄清。
4. 只在友谊箱放木头，要求“附近建一个木牌，只用箱子的材料”，核实取材→木板→预制→新建筑。移走材料应报告真实短缺；移除科技站／未解锁、角色或技能不符不应绕过。缺额外科技设施只报告，不擅自建站。
5. 在预制完成、施工前暂停；使固定点被占用，再继续。应保留预制、只扣一次材料、不会挪点。修改点位重新提交应使旧动作失效；取消应说明预制已扣材料且仍保留。重载后原版Builder预制应保留；现有任务队列本轮未增加跨重启持久化，需重新发起目标复用预制。
6. 固定点上分别放可携带掉落物和已有建筑：只在原版地图确实判定阻挡时拾取前者；满包报告，不能捡起又丢回。后者停下，不拆除、砍树、挖树桩、点火或战斗。施工前再放障碍，仍须重新核实。
7. “附近建一个晾肉架和一把鹤嘴锄”，核实建筑与物品分别记账；让建筑条件不足时，工具仍能完成。固定两座木牌必须有两次不同点选；自由两座应分开合法位置，旧木牌不顶新增数量。
8. 两个朋友点相邻冲突位置；第二项应说明施工预留冲突。暂停／取消第一位后可继续第二位。玩家照常在该点建造后，朋友应发现现场变化。尝试不可达点和跨分片旧点，不能长期盲走或把BUILD发出视为完成。
9. 最少回归花瓣采集与交付、普通装备制作与存箱、知识连续追问、暂停／恢复／修改／取消、补状态后接续。较长材料链超过一分钟仍有效推进；不能恢复固定一分钟总限制。

发现问题请提供当前server_log和对应原句，注明服务器／客户端版本、分片、点选坐标、是否已预制。不要提供密钥。
