# v0.14.0-r4 通用规则、改动与最少游戏测试

## r2 → r3 → r4 的区别

r3 主要修复语言入口、指代、真实回答回传和比较；用途 1,125、机制 830 基本不变，来源 680→681、行为 0→4 是少量集中适配，不能称为百科完成。r4 用作用域 AST、构造参数、公共初始化函数、TUNING、实际组件接口、行为树和生成房间关系批量提取，另建立材料反向配方、分类和关系索引。没有按未见抽样对象补适配。

## 架构与事实门槛

1. 离线 Reader 只静态解释受限语法：跟踪返回 Prefab 的构造函数、工厂参数、公共初始化函数和所属实体；纯常量表达式可求值。未知条件分支、循环、任意事件／装备／使用回调不执行、不猜测、不提升为事实。次级实体不会污染主体。TUNING 是默认生存服务器基准，世界覆盖和状态变化另需核对。
2. 工具按实际动作、效率、消耗及基准耐久；装备按装备位、护甲、精神变化、保温、防水等；材料按确认配方反向关系；食物按图鉴／组件效果及受限烹饪谓词；设施按容器、科技、烹饪、干燥、传送、睡眠等组件功能与条件；生物按实际关联行为树、基础掉落及生成区域。行为树中有追击动作不等于永远敌对，房间生成权重不等于当前地图位置。
3. 来源区分采摘、掉落和加工，不能把对象自己的产物当成该对象的获取来源。同一概率表的多次抽取保留为列表，不误当冲突，不计算未经核验的总体概率。完整源码片段仍留为候选，不能直接变成解释。
4. 基础身份索引、细节分片、分类／反向配方／关系／条件索引分别存放。知识与动作权限独立，未增攻击、拆除、点火或主动行为。配方知识不授予建造和特殊设施执行能力。

## 语义入口与会话

支持插字、漏字、替换、相邻交换、工具词头归一和简称候选；按名称相似度、类别及近期话题排序。黄金斧子的斧类词头和黄金限定不会消失；蝙蝠可关联洞穴蝙蝠。明确且唯一的知识候选可说明“应该是”后回答，动作仍严格核验。未知真限定词保留；语法边界独立于名称保护，多对象不只取最长名称。

分类按本地有依据的成员关系分页，区别官方目录与库存。家族／阶段可聚合，独立对象、状态、皮肤不能互换；仅名称与身份前缀相关的组明确称为名称组，玩法关系未核验。中文同名候选按唯一身份去重并附区分标签，不再只列重复名称；尚无可靠特征时使用中文类别及序号，不暴露内部 ID。

条件问句提取参与对象、动作、数量与条件，优先于任务执行。当前猪人规则来自两个构造身份注册的 OnEat AST 契约和 werebeast 阈值：实际食用有负生命效果的肉类、正常形态、从零累计等条件不可省略。不会执行回调来试验，也不会把所有条件问题编成确定结果。

待确认请求与普通话题分开：保存原问题、候选、类型及请求；确认优先于旧话题，多个候选“是的”不任选。过期、取消、换题及不同玩家隔离；实际最终回答继续通过结果回传保存。历史不重放命令。

## 回答与调用次数

本地负责确认事实、版本和执行校验；模型负责理解问题并选择受限表达顺序（direct／overview）。游戏端以确认事实组成简短完整句子，不接受模型自由补数值和机制。相同装备概括合并，材料用途汇总，配方按问题输出，指南针优先导航功能。长内容分页或择重点，不切半句。服务不可用时沿用有依据的本地查询反馈。

普通请求仍一次模型调用，没有新增百科润色调用；实际回答回传增加本地 HTTP POST，不调用模型。诊断开关是本地命令，0 次模型调用。真实延迟未测；重试沿用原传输行为。

## 最少游戏验收

1. 同时更新模组和后台，确认 health 的 r4 与构建 756039。按下面问题测试，确认查询没有启动任务、攻击或拆除。
2. “黄金斧子有什么用”“蝙蝠是什么”“烧灼园艺锄有什么用”；再用损坏或升级等限定请求采集，不能静默变普通工具。
3. “黄金工具有哪些”“你知道哪些建材”“有哪些恢复精神的食物”“继续展开”；应按目录列举，有范围与分页，不冒充库存。
4. “介绍全部墨荒”“天体英雄有哪些阶段”“普通毒菌蟾蜍和特殊版本有什么区别”；查看独立身份／状态／额外战斗分支说明。名称组未核验的关系应明说。
5. “猪人吃了4个怪物肉会怎样”“猪人吃了3个怪物肉会怎样”“猪人吃了4个浆果会怎样”；回答实际食用、形态和累计前提，不启动喂食或采集。
6. 先问玻璃刀，再问“遮阳棚有什么用”，确认“是的，就是这个”；必须回答原遮阳篷问题。多候选的“是的”需继续确认。再测试“这个怎么做”、取消查询、换话题及两名玩家隔离。
7. 未见样本中任选物品／生物／建筑各一条；“棕榈松果树鳞片能用来制作什么”“芦笋汤怎么烹饪”“普通镐和黄金镐有什么区别”。不能只报类别或生命值，未知部分具体指出，不泄露技术标识或重复配方。
8. “你给我采点花瓣呗”：普通花朵采摘、花瓣实际入包并按指定数量交付；另一普通采摘与树枝采集各做一次。工作中暂停、恢复和取消仅做必要回归，取消后旧动作不得继续。模型对“点”的数量理解仍需游戏验证。
9. 失败时输入“开启知识诊断”，复现后“关闭知识诊断”，保存同一请求链。默认详细诊断关闭，密钥脱敏；保留原句、名称跨度、候选、模型选择、本地核验、引用事实和最终回答。

请勿把本地模拟通过视为以上游戏实测已通过。全面知识最终目标保持，剩余工作见覆盖报告。
