# v0.16.0-r6：按玩家站位进行地皮吸附

基线：已由玩家测试的 v0.16.0-r5。游戏参考脚本：此前提供的 DST 构建 756039。本轮只修复第三种定位方式，不重写材料、建筑执行或工作控制系统。

## 根因与改动

r5 将“在我这”“在我脚下”“我的位置”等解析为 player，并在初始化及位置修改流程中直接保存精准站位；模型提示也要求精准坐标。已有 Tile() 的 cell / edge / corner / auto 算法没有接入这些表达。此外，不带“这”字的“按两格中间建”未被本地解析覆盖。

现在上述站位表达统一为 tile/auto；明确“按这格中心建”为 cell，“按两格中间建”为 edge，“按四格交点建”为 corner。同步调整模型提示、后端结构校验、游戏端结构校验、任务初始化和位置修改。旧 player 结构仅作为兼容别名转换成 tile/auto，不保留精准玩家坐标模式。单项目标的定位也经过规范化。

继续使用原有 Tile() 和运行时 Map:GetTileCoordsAtPoint / Map:GetTileCenterPoint，依据相邻格中心计算网格方向与尺寸，不写死地皮大小或地图原点。当前脚本 components/map.lua 中的原版调用同样使用这两个接口；接口底层引擎实现未在 Lua 源码中，实机接口行为仍须游戏验收。

自动优先级为交点 > 公共边 > 单格中心。吸附阈值沿用模组配置：默认地皮宽度的 15%，可选 10% / 20%。比较包含边界，并增加极小的浮点容差。每条有效指令只定位一次，因此玩家后续移动、暂停和恢复不会造成阈值附近持续抖动。不比较相邻地皮的地形类别。

记录原始站位与世界分片、吸附类型及最终位置，输出一次 tile_location 日志。暂停恢复复用已记录位置；明确修改定位时才重新捕获站位、重新吸附，并沿用原有动作失效机制和预制状态。无法唯一确定明确要求的两格或四格组时，提示玩家靠近对应边/交点，不猜测。

附近 free 保持有限搜索；鼠标 fixed 保持点击的精准坐标，不吸附。吸附点非法时保留原点并说明阻碍，不偷偷偏移、不要求玩家让开，最终放置仍由原版检查决定。

## 验证

77 项 Python 测试通过；建筑集成、真实自然语言入口的模拟提供器回归、Lua 工作回归和通信基础回归通过。

建筑模拟直接比较建成实体坐标，覆盖偏离中心、横/纵公共边、交点、阈值内外及边界、跨边两侧、负坐标区域、不同地形、玩家移动、模型响应前移动、暂停恢复、修改定位、非法点不偏移、跨分片拒绝。保留自由建造、固定点选、仓库取材、递归材料制作、预制与放置、取消及原版障碍检查回归。

自然语言入口经真实 HTTP/决策解码及生产游戏聊天入口，模型提供器、世界、路径及状态图依赖是模拟；不是实际模型调用或 DST 游戏实测。Lua 语法检查使用 5.4，DST 5.1 引擎未运行。包中 tests/v0160_r6_* 日志保留验证记录。

## 最少游戏验收

同步更新客户端/服务器模组与 external 后端，保留密钥配置并重启。选择有足够空地及材料的地方，用木牌等普通建筑测试；每项选择新的空位，避免上一座建筑影响原版间距判定。

1. 在地皮中部偏离中心站立，说“在我这建一个木牌”；发话后移动。核实实际木牌实体落在该格中心。
2. 分别靠近横向、纵向公共边，说“在我脚下造一个木牌”。核实实际实体落在公共边中点；靠近四格交点重复，核实落在交点。
3. 在吸附阈值两侧测试；换一个远离原点的坐标区域重复。明确“按这格中心建”“按两格中间建”“按四格交点建”，检查覆盖自动选择；在组不明确的位置请求两格/四格，应澄清。
4. 材料未齐时暂停任务、移动并恢复；原位置不能改变。再使用“改为在我脚下建”修改定位，只有这次修改才重新记录。
5. 用“附近找个地方建”检查 free；用“建在我指定的位置”在偏离格中心处点选，实际实体必须保持点击坐标。测试非法吸附点，不得自行偏移。

验收依据实际实体坐标，不依据提示或标记。服务器日志的 tile_location 包含原始站位、吸附类型与目标坐标；verified 包含实际建筑实体及坐标。游戏端服务器控制台可用已核实日志中的实体 GUID 查询 Ents[GUID].Transform:GetWorldPosition()；核对最终坐标与目标坐标。若停滞，保留 [YBF POINT] / [YBF BUILD] / [YBF BUILD FLOW] 日志。
