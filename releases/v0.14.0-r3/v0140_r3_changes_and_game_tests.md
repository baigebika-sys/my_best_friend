# v0.14.0-r3 根因与改动

## 语言入口

r2 把名称前后不在固定 fillers/endings 中的文字全当限定词，正常语气、谓语和连接词因此被拦截。现在按请求框架、名称跨度和问句谓语拆分，保留黄金、烧灼、损坏及未知名称修饰。重叠名称优先完整跨度；不重叠的多个对象全部保留。别名和相邻字交换／合理单字错字产生候选，不能自动确认有歧义的版本。模型选择还要匹配玩家原句及候选依据；执行仍使用核实身份。

这是一套有边界的语言规则，不声称已解决任意中文句式。暗影甲在暗夜甲／虚空长袍间询问，确认只显示中文名；水獭、黄金镐子采用集中核验别名。泛化规则在 ybf_knowledge_names.lua，事实和适配集中在知识层。

## 指代与真实记忆

r2 对当前句无名称的知识请求过度拒绝；桥接历史对非 none 结果存入执行未确认占位句。现在会话按朋友和玩家隔离，保存最近讨论对象、待确认候选和实际回答。单一讨论对象允许只读指代；多个对象询问。候选确认 90 秒过期，不能授予工作动作；上下文不重放旧命令。

游戏端实际呈现后 POST /tasks/<id>/result，核对请求、实例、朋友和会话，重复回传幂等，冲突拒绝。桥接新客户端不在 GET 时记忆模型临时话语。每会话最多 6 轮、6000 字节，10 分钟过期；按请求顺序保存。回传失败可由下一次游戏快照提供实际最近回答，日志保留同步失败。密钥与疑似密钥文本在历史和详细诊断中脱敏。

## 检索与整体比较

识别介绍、用途、配方、环境、比较及科技概念，原问题决定栏目；不让模型的错误栏目覆盖明确问句。介绍可用已确认行为／用途／机制，不把单一空栏目当整条无知识。环境事实只说通常生成／栖息条件，不冒充当前坐标。概念单独查核实说明。

比较读取属性、材料、科技和特殊机制，按维度一次组织两个对象：普通镐 33 次、黄金镐 132 次及材料差异都来自现有事实。未知特殊效果明确标记。实时属性与静态基准分开，同一对象状态和皮肤不作独立物品。

## 自然回答与调用成本

采用本地受控自然语言组织器 ybf_knowledge_presentation.lua，事实必须有来源、确定程度和版本匹配。先直接回答，按问题加入必要条件；运行时配方优先静态配方，不重复列。按完整句子选重点，避免机械截断；内部身份、字段和诊断仅写日志。服务不可用时已识别的只读查询仍可用本地事实回答，不自动开始工作。

普通请求保持一次模型解释调用，没有新增回答润色调用。实际回答回传增加一次本地 HTTP POST，不调用模型。开启／关闭知识诊断为本地命令，0 次模型调用。固定解释规则“点／一点／一些”沿用每种默认 3 并应说明；模拟 fixture 用 1 验证动作和交付，不代表真实模型数量解析通过。传输重试仍沿用原协议；实际延迟未用真实模型测量。

## 知识补充与修正

继续从官方图鉴、组件及集中审阅脚本补用途、行为、限制和环境；原始代码候选仍不可作已确认解释。补水獭行为及窝点条件、皮弗娄牛敌对和生成条件、暗夜甲精神消耗、工具采矿用途。图鉴明确文字按主题索引，不把关键词当完整机制推导。

纠正 r2 对 inspectable.nameoverride 的理解：它覆盖检查描述；显示名称依据 EntityScript 的对象 nameoverride。这一事实包含组件声明的附加证据，不再创造假的动态名称关系。

## 诊断

在朋友聊天输入“开启知识诊断”，复现后输入“关闭知识诊断”。默认不输出详细知识链。开启后日志关联请求 ID、原句、名称跨度和候选、模型选择、本地核验、检索事实与引用及实际最终回答。类别区分名称失败、检索缺口、知识缺失、指代歧义和生成失败。沿用原传输状态日志，不含 API 密钥。

## 最少游戏验收

同时更新模组和后台、保留自己的密钥，确认两端 revision r3。以下由你在真实游戏完成，当前未完成：

1. 附近放置至少 3 朵普通花，输入“你给我采点花瓣呗”，确认目标数量、实际采摘入包和交付；再用“能不能帮我采一点花瓣呀”。“给我损坏的黄金镐”不得静默采集普通黄金镐；“灼烧园艺锄”需中文确认。
2. 连续问“你知道独奏乐器吗”“独奏乐器有什么用”“独奏乐器怎么做”，应有简短介绍、用途和一次配方，不能开始工作。
3. “普通镐和黄金镐有什么区别”：应整体比较 33／132 次及材料；再问“它怎么做”需确认指哪种，回答“黄金镐子”接续配方。
4. “水獭是什么”→“这是怎样的一种生物”→“水獭在哪里”；只描述核实行为与通常环境，不声称当前地图位置。再问“暗影操控器是什么”→“这个怎么做的”，应接续其配方。
5. “暗影甲有什么用”应以暗夜甲／虚空长袍消歧。“科技是什么”不按物品名称拒绝。两位玩家对同一朋友追问，不得串对象与回答。
6. 请求基础树枝采集，再暂停、取消，确认暂停后不继续旧动作、取消不交付旧任务。没有新主动行为。
7. 若有失败，开启知识诊断复现，再关闭，保存同请求完整链。检查回答没有内部 ID、重复配方或半句截断。

真实模型对新语气、别名及数量的理解仍需实测。本地失败时不靠补截图特判掩盖；完整百科缺口见覆盖报告。
