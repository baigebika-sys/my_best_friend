# 当前官方游戏数据：需要你提供的文件

目前无法确定要支持的 DST 数字构建号。v0.14.0 / 0.14.0-r1 是模组版本，不是游戏构建号。上一包的少量公开参考脚本没有当前构建号、完整官方目录或中文本地化，不能用于宣称当前版本全覆盖。

请从你实际测试的同一份官方安装中收集：

| 文件 | 用途 |
| --- | --- |
| 游戏安装根目录的 version.txt（若实际在 data 内也可） | 固定实际数字构建号；不要自己填写猜测版本 |
| data/scripts.zip | 完整官方脚本：prefabs、组件、动作、配方、调参、AI、状态图等 |
| 简体中文 chinese_s.po 或实际所用中文本地化文件 | 中文正式名称与英文名称对应；可能在 scripts.zip 的 scripts/languages 内，或安装目录 data/scripts/languages 内 |
| 若脚本不是 ZIP：完整 data/scripts 目录，保留原路径 | 同等替代输入，需要完整而非只选几个 prefab 文件 |

## 查找安装位置

Steam 库 → 右键“饥荒联机版 / Don't Starve Together” → 管理 → 浏览本地文件。打开安装根目录及 data 文件夹。先更新到你要验收的稳定分支，并说明是否测试版、是否联机主机/独立服务器、中文语言设置及启用的第三方模组。

若联机主机/专服与客户端安装不同，请分别提供各自 version.txt；知识目标应以实际运行世界的服务端构建为准。没有 version.txt 时请提供游戏启动日志中显示构建号的那几行，再提供 scripts.zip；不要用网页“最新版”代替。

## 自动收集（有 Python 时）

解压本交付包，在交付根目录运行，替换安装路径：

```powershell
python developer_tools/collect_dst_knowledge.py --game-dir "D:\SteamLibrary\steamapps\common\Don't Starve Together" --output "dst_knowledge_input.zip"
```

把生成的 dst_knowledge_input.zip 上传到对话。该工具只收集构建标记、scripts.zip 和中文 PO，附字节数与 SHA256；不收集存档、mods、账号、密钥。若不愿运行脚本，手动复制以上文件并打包也可以。

工具找不到 version.txt 或 scripts.zip 时会停止，不会联网下载旧数据冒充当前安装。中文文件未找到时会在清单中标记 missing_localization；请提供目录截图或实际中文文件。中文不是简体时也请说明。

## 对“灼烧园艺锄”的核实

本轮没有收到显示该道具实际名称/机制的游戏截图或当前游戏数据，所以没有给它预先指定官方 prefab，也没有认定它一定是独立道具。请同时提供显示完整名称与物品说明的游戏截图，说明是否有模组改名/皮肤以及出现前后的操作。这能帮助区分独立 prefab、同一对象的状态、皮肤或动态显示名称。

收集文件不会自动完成百科：收到后还需要重建目录、核验动态生成身份、审查重要机制、补充当前版本的官方说明/可靠百科，并重新生成真实覆盖报告。
